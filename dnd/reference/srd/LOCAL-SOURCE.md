# Local SRD source

This directory vendors the Markdown source from [5thSRD](https://github.com/vitusventure/5thSRD) at commit `e1a79135cef95245102aeaef9ee910ea4ad1207f`.

The app builds its searchable Rules Reference from these files with `node scripts/build-srd-reference.mjs`. Blood Hunter and other non-SRD or campaign-specific rules remain separate from this source.
